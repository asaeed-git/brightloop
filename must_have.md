# Project Requirements

- **Data Sources:** Use real-time or dynamic data sources, and avoid relying on static JSON unless it's for initial prototyping.
- **User Interface:** Create a responsive and clean UI (Consistent color scheme and layout).
- **Input Handling:** Validate user input robustly.
- **Navigation:** Use intuitive navigation with proper menu placement and spacing.
- **Version Control:** Use version control (Git) properly; one member managing the repo is not enough.
